Week 1 — Foundations & GitHub Setup

    >Installed Python, VS Code, and GitHub Desktop >Created the GitHub repository and project folder structure >Wrote Vision.md, Project_Constitution.md, and README
Key concept: Version control with Git allows you to track every change made to your project and revert if something goes wrong.

Week 2 — First Live Data Pull

    >Set up Python virtual environment and installed yfinance >Built fetch_data.py to pull live stock data from Yahoo Finance >Saved company snapshots (market cap, EPS, FCF) to data/raw/
Key concept: yfinance is a free Python library that connects to Yahoo Finance and returns real company financial data as Python dictionaries.

Week 3 — Scoring Engine v1

    >Built scoring.py with two scoring functions >score_revenue_growth(): calculates 3-year revenue CAGR, scores 0–100 >score_financial_strength(): calculates interest coverage ratio, scores 0–100 >Tested on MSFT, NVDA, COST
Key concept: CAGR (Compound Annual Growth Rate) measures how fast revenue grows per year on average. A 15% CAGR means revenue doubles roughly every 5 years.

Week 4 — Working Dashboard MVP

    >Built dashboard.html, style.css, and dashboard.js >Built export_dashboard_data.py to aggregate scores into dashboard_data.json >Dashboard loads in browser showing company rankings with score bars
Key concept: A static HTML dashboard reads a JSON file to display data. No backend server needed — the browser does all the rendering using JavaScript.

Week 5 — Expand Company Universe

    >Created data/watchlist.json with 19 growth stock tickers >Updated fetch_data.py and scoring.py to read from watchlist.json >Scored all 19 companies and confirmed dashboard shows full universe
Key concept: Separating configuration (watchlist.json) from code (scoring.py) makes it easy to add or remove companies without changing any Python code.

Week 6 — SEC Filings & Key Financials

    >Built fetch_sec.py to fetch 10-K filings from SEC EDGAR for all 19 tickers >Added EPS, P/E Ratio, and Revenue to each company's data >Built a popup modal on the dashboard showing SEC filing details and financials
Key concept: The SEC EDGAR database is free and public. Every US public company must file annual reports (10-K) which contain detailed financial information.

Week 7 — News & Company Comparison

    >Built news_proxy.py using Flask to fetch live Yahoo Finance RSS news feeds >Added live news headlines as clickable links on each company row >Built company comparison panel showing two companies side by side >Created run.py to start all servers with one command
Key concept: RSS feeds are free data streams that websites publish. A local Flask proxy server fetches them on behalf of the browser, bypassing browser security restrictions.
